# Automated Work Assistant

Act as an expert Full-Stack Developer and UI/UX Designer. Please build a modern, responsive React web application called "WorkFlow AI" designed to automate repetitive professional tasks. Use Tailwind CSS for styling and modern UI components (like Shadcn UI) to give it a polished, enterprise SaaS look (light mode with subtle grays, primary blue accents, and clean borders).

APP STRUCTURE & NAVIGATION:

- Create a persistent Left Sidebar navigation with three main tools: "Smart Email", "Meeting Summarizer", and "Task Planner".

- Create a Top Header that includes the app title and a persistent "Responsible AI Disclaimer" banner that reads: "AI outputs are generated by models and may contain errors or biases. Always review and validate content before professional use."

- Create a centralized state to handle loading spinners when AI tools are "generating."

FEATURE 1: SMART EMAIL GENERATOR

- UI: A two-column layout. Left column for inputs, right column for the AI output.

- Inputs: 

  1. Text input for "Email Context / Goal".

  2. Dropdown for "Tone" (Formal, Informal, Persuasive).

  3. Dropdown for "Audience" (Client, Manager, Team).

  4. "Generate Email" button.

- Output: A card displaying the generated email text with a "Copy to Clipboard" icon button.

- Functionality: Mock the generation process with a 2-second loading state, then display a realistic placeholder email based on the inputs.

FEATURE 2: MEETING NOTES SUMMARIZER

- UI: A clean workspace with a large text area at the top for pasting raw notes.

- Inputs: A large textarea labeled "Paste raw meeting transcript or notes here", and a "Summarize Notes" button.

- Output: Below the input, generate a structured output card with three distinct sections:

  1. "Executive Summary" (short paragraph).

  2. "Action Items & Responsibilities" (checklist format).

  3. "Deadlines" (highlighted badges or bolded dates).

- Functionality: Mock the generation with a loading state, then display a structured placeholder summary.

FEATURE 3: AI TASK PLANNER / SCHEDULER

- UI: A dynamic input area and a visual schedule output.

- Inputs: A textarea labeled "Braindump your tasks for the week (one per line)" and a "Generate Optimized Plan" button.

- Output: A visually structured timeline or Kanban-style board showing:

  1. "High Priority / Do Today".

  2. "Medium Priority / Schedule".

  3. "Low Priority / Delegate".

- Functionality: Include a visual "Time Optimization Tip" generated alongside the schedule. Mock the loading and result state.

TECHNICAL & PROMPT ENGINEERING SCAFFOLDING:

- Create a separate utility file (e.g., `ai-service.js` or similar) where the actual API calls to OpenAI/Anthropic would go. 

- In this utility file, clearly define constants for the "System Prompts" for all three tools so that I can easily edit and refine the prompt engineering logic later. Leave comments indicating where the API keys and fetch requests will be injected.
